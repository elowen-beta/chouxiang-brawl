# 抽象大乱斗

一场在浏览器里开打的本地平台乱斗。两到四个人挤在同一台键盘上（也可以插手柄），把对手打出装配台。

百分比会越积越高，打得越重、飞得越远。每人 3 条命，最后留在台上的人赢。

把你喜欢的角色加进大乱斗：花名册是几份数据，不是一份写死的名单。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

```bash
npm test        # 击飞、站台、命中、KO
npm run build   # 类型检查并打包到 dist/
npm run preview # 预览打包结果
```

## 怎么玩

标题画面按任意键进入选人。按 `8` 可以先看一场四位练习伙伴的互殴。

选人时，每位玩家用自己的左右键换角色，用下键把自己换成练习伙伴。同一位角色可以被多个人同时选。`Q` / `E` 拉上第三、第四位。`Enter` 开打。

| 动作 | P1 | P2 | P3 | P4 | 手柄 |
| --- | --- | --- | --- | --- | --- |
| 移动 | A / D | ← / → | F / H | U / O | 左摇杆、十字键 |
| 跳 | W | ↑ | T | I | A（南键） |
| 下 | S | ↓ | G | P | 左摇杆下 |
| 轻击 | J | 1 | C | Y | X（西键） |
| 重击 | K | 2 | V | [ | Y（北键） |
| 上攻 | L | 3 | B | ] | B（东键） |

轻击在地上是平 A，按住下是下招；在空中是周身，按住下是下砸。重击在地上往前砸，在空中是前方重击。上攻在空中会把自己往上带一截，用来抓回装配台。短按跳是小跳。按住下可以从两侧云台穿下去。

掉出画面四周的爆破区会失去一条命，百分比清零后从台上重新落下，并短暂打不中。三条命用完就出局。`Esc` 暂停，`M` 开关声音，`F2` 看手感数字。

## 把你喜欢的角色加进大乱斗

1. 复制 [`src/data/characters/fangfang.ts`](src/data/characters/fangfang.ts)。方方是写全了的模板；滚滚、刺刺、稳稳是在这份招式上改了几项手感。
2. 改 `id`、`name`、`epithet`、`blurb`、颜色、`shape`（`square` / `circle` / `diamond` / `hex`），还有体重、重力、移动和跳跃。
3. 八个招式槽都要在：`jab`、`fstrong`、`utilt`、`dtilt`、`nair`、`fair`、`uair`、`dair`。伤害、击飞、角度、出招帧、判定框都可以不一样。
4. 在 [`src/game/roster.ts`](src/game/roster.ts) 里 import，放进 `roster` 数组。

存盘后刷新，选人画面上就会多出一位。缺招式或 `id` 重复时，启动会直接报错，告诉你缺了哪一招。

想先借别人的体型，再慢慢换成自己的数值，就从方方抄一份改名字。判定框、体重和 `knockbackGrowth` 是手感的三颗螺丝。

## 规则

- 3 条命。不设计时，也不进突然死亡。
- 命中后把伤害加进百分比，再按百分比、招式和体重算击飞。
- 打出画面四周的爆破区算一次 KO。
- 2 到 4 人混战，没有队伍。最后还剩命的人赢。
- 台上的几何人是占位演员。喜欢谁，就把谁的手感写进数据。
